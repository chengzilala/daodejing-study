## 1 项目概述

- **产品定位**：面向零基础读者的《道德经》学习网站——原文 + 白话 + 逐章导读，让人「读得进去、看得懂」。
- **目标用户**：零基础、想读《道德经》但读不懂原文的普通读者。
- **形态**：纯静态网站，无后端、无数据库，可直接部署（如 Vercel）。
- **当前状态**：v1.0.0 已完成，本地可构建、可预览。

## 3 详细功能需求

### 3.1 首页
- **需求**：展示 81 章卡片列表，每张卡片含「第N章 + 章题（主题词）」。
- **交互**：顶部分组 tab（全部 / 道篇 / 德篇）切换，按章号 1–37 归道篇、38–81 归德篇。
- **主题切换**：右上角按钮在「古卷黄 ↔ 墨色」间切换，`localStorage` 记忆；默认古卷黄。

### 3.2 章节页
- **需求**：单章阅读，三段结构「原文 / 白话 / 导读」。
- **导航**：上一章 / 下一章；首章无上一章、末章无下一章（占位为空）。返回目录按钮。
- **标注**：页面底部标注「原文据通行本（王弼本）；白话、导读均为『编者解读』，非定论」。

### 3.3 内容格式（构建脚本解析依据）
每章 Markdown 固定为三段：

```markdown
## 第1章 体道

### 原文
（原文，据王弼本通行本）

### 白话
（白话）

### 导读
（导读）
```

- **原文**：据通行本（王弼本）。
- **章题**：据河上公本（如「体道」「养身」等）。
- **白话 / 导读**：均为「编者解读」，非定论。

## 4 UI·UX 需求

### 4.1 背景：古书 / 古绢质感（2026-10-01 确认，已实现）
- **不用纯色**：古卷黄底 #efe0b6 + 多层纹理（径向渐变做明暗不匀 + 折痕 + 经纬织纹 + 内联 SVG `feTurbulence` 噪点）。
- **双主题**：`body.ddj-ink` 覆盖 CSS 变量，切换为墨色深底 #27231d + 米白字，暗色下仍保留绢本质感。
- **古书元素**：标题朱红印章、卡片双线版框（`border` + `outline` offset）、正文区半透明纸面衬底。
- **性能**：全部 CSS / 内联 SVG 生成纹理，零图片请求、零外部依赖。

### 4.2 排版
- 原文大字（约 21px）、宽行距；导读/白话字号适中。
- 响应式：窄屏（≤640px）卡片两列。
- CSS 类名统一 `ddj-` 前缀，防样式污染。

## 5 技术实现方案（已实现）

- **纯静态管线**：`web/content/*.md`（Markdown）→ `web/build.py`（Python 3 标准库）→ `web/dist/*.html`。
- **构建脚本** `web/build.py`：
  - 正则解析 `## 第N章 章题` 与 `### 原文/白话/导读`。
  - `cn_num()` 把章号转中文（1→一、10→十、81→八十一）。
  - 模板替换：模板用 `@@KEY@@` 占位符，`str.replace` 填入。
  - 生成 `index.html` + `chapter/N.html`，复制 `assets/`。
- **本地预览** `web/serve.py`：`http.server` 指向 `web/dist/`，端口 5173。
- **内容文件**：81 章按 9 章一组拆为 `content/part-01.md` ~ `part-09.md`。
- **配置** `web/site.config.json`：站名「道德经」、站点描述、端口。
- **模板**：`templates/index.html`、`templates/chapter.html`。
- **资源**：`assets/css/style.css`（主题变量 + 纹理 + 布局）、`assets/js/main.js`（主题切换 + 分组过滤）。
- **部署**：`web/vercel.json` 配置 `buildCommand: python3 build.py`，输出 `dist/`。

### 对比（3 个风格代表）

| | A 传统门户型 | B 学术对照型 | C 现代极简阅读型（✅选定） |
|---|---|---|---|
| 代表站 | 道德经网 daodejing.org | 中国哲学书电子化计划 ctext.org | 帛书版道德经 hugtogether.com |
| 栏目结构 | 顶部多行导航 + 81 章表格网格 | 左侧树形目录 + 检索/字典/影印 | 顶部分组切换（道篇/德篇）+ 章序卡片 |
| 章节导航 | 点数字直达 | 树形逐章展开 | 章标题卡片，每章带主题词 |
| 阅读交互 | 原文+译文分栏、生僻字注音 | 原文+译文逐句对齐、悬停查字典 | 每章「原文 + 白话」分块，干净 |
| 定位 | 信息全的百科门户 | 严谨的研究工具 | 轻量、像手机阅读 App |

### 选定结论

- **选定 C 现代极简阅读型**，理由：贴合「零基础读者读得进、看得懂」的定位，视觉干净、移动友好。
- 可借鉴的具体点：①顶部分组切换（道篇 1–37 / 德篇 38–81）；②章序卡片列表、每章配主题词；③章节内「原文 / 白话 / 导读」分块；④正文大字号、宽行距。
- 内容仍以**权威通行本**为准（不用帛书本的德篇在前章序），仅借鉴其排版结构。
